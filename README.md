# Studio Ana Heloísa — demonstração

Execute npm install e npm run dev. Acesse /agendar e /admin no mesmo navegador. Use apenas dados fictícios. Serviços e horários são ilustrativos.

Os dados ficam no localStorage, sem autenticação e sem sincronização entre dispositivos. Não há garantia de exclusividade em acessos simultâneos. Não use para clientes reais ou produção. Restaurar os dados apaga as alterações da demonstração.
